# MediCare — Web-Based Hospital Appointment & Telemedicine System

> **Pre-print DOI:** [10.5281/zenodo.23235454](https://zenodo.org/records/23235454)  
> **Journal Submission:** Submitted for peer review at *Sukkur IBA Journal of Computing and Mathematical Sciences* (SJCMS ID: 1912).

## Overview
MediCare is an integrated, multi-user healthcare platform engineered to address OPD congestion and regional medical access limitations. The system unifies appointment scheduling, real-time browser consultations, digital prescription handling, and local mobile payment verification.

---

## Core Features
- **Real-Time Video Consultations:** Peer-to-peer WebRTC video integration for instant browser-based telemedicine calls.
- **Local Payment Gateway:** Automated transaction verification supporting Pakistani mobile wallets (**EasyPaisa** and **JazzCash**).
- **Role-Based Access Control (RBAC):** Dedicated portal dashboards for **Patients**, **Doctors**, and **System Administrators**.
- **Digital Prescriptions:** Automated prescription generation and record management.

---

## Tech Stack
- **Frontend:** HTML5, CSS3, JavaScript (ES6+), Bootstrap
- **Backend:** PHP
- **Database:** MySQL
- **Real-Time Streaming:** WebRTC API
- **Documentation:** LaTeX (IEEE Format)
